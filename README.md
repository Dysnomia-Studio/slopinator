# Installation

**Chrome web store (Chrome/Opera):** https://chromewebstore.google.com/detail/slop-inator/hgflafbjgbapndncdllnmkefinafckoj  
**Firefox addon store:** https://addons.mozilla.org/fr/firefox/addon/slop-inator/  
**On the Steam client:**
- Open the steam client, and go to the store
- Right click on any link then "Open link in new tab"
- Paste the extension url in the URI bar: https://chromewebstore.google.com/detail/slop-inator/hgflafbjgbapndncdllnmkefinafckoj
- Click "Add to Chrome"
- Click "Save" (it won't save it anywhere, but it works)
- Reload the steam client store page
- Enjoy!

Pre-release versions are also available in the "Releases" tab.  

# Details on the badges

## Badges

There are a few badges available generated by the extension
- Art: 2D Assets, Textures, 3D models, Animations, ... Any visual asset in the game/app
- Code: Anything related to programming the app/game
- Marketing: Text or pictures used on store pages, social medias, advertisement, ...
- Sound: VFX, music, ... but not voices
- Translation: translating from one language to another
- Voice: any voice in the game 

## Colors

- Green (human icon): Fully human made, no genai involved in the final result or in the process
- Orange (warning icon): Warning (unsure) or Past usage. Need to be reviewed/sourced more, or has been used in the past (e.g. placeholders replaced by human work. Art editing on top of AI work is not valid for this category)
- Red ("AI" icon): AI Usage
- White ("?" icon"): Unknown usage

# Contribution

You can add new data on Steam Games, or update them by editing the files or adding new files in [data/](data/).  
**Please make one Pull Request per game, and add sources URLs for any new data.**  
*Do not edit autogenerated files such as `steam_app_data.json`.*  
*No witch hunting please, we want facts, we want data with trusted sources!*

If you want to contribute to the extension code, please refer to the [Wxt Documentation](https://wxt.dev/guide/installation.html), and produce clear, understandable, maintenable code. One pull request per feature/bug fix is required.

# Privacy & Data shared

Your privacy is important. I will never recieve any of your data nor does any third party service. No telemetry is used.
